Summarisation of the As

This page is being served from an S3 bucket you created from scratch. No physical server. No wires. Just abstraction, a few API calls, and a little agility.

What's happening behind this page

  • Abstraction: AWS hides the hardware; you see a URL.
  • Availability Zones: your files are copied across data centres.
  • Access Control: IAM decides who can change this site.
  • Alarms & Alerts: a billing alarm is watching your costs.
  • Automation: this was deployed with a script / CloudFormation.
